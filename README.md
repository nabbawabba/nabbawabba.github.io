# Jennifer Ren Personal Website

Static one-page portfolio site.

## Files

- `index.html`: main page
- `styles.css`: styling and layout
- `Jennifer_Ren_Resume.pdf`: resume download shown on the site

## Run locally

Open `index.html` directly in a browser, or serve the folder with:

```bash
python3 -m http.server
```

## Replace placeholders

- Main hero photo: `assets/headshot-main.jpg`
- Artistic rendition: `assets/artwork.jpg`
- Poker photo: `assets/poker.jpg`
- Project visuals: replace the decorative cards in the Projects section with screenshots, GIFs, or demo links

## Notes

- Phone number is intentionally omitted from the public site
- LinkedIn and email are the only public contact methods
- The project cards are designed to work without linking source code
